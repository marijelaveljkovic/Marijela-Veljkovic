## 🚀 Featured projects

### [Sous-Vide Controller (ESP32-C3)](https://github.com/marijelaveljkovic/sous-vide-controller-esp32) · BSc thesis
Sous-vide cooking device built from scratch: PID temperature control with anti-windup, time-proportional SSR control of a 2 kW heater, FreeRTOS firmware and a WiFi web dashboard. Experimental tuning reduced temperature overshoot from ~3 °C to ~1 °C.
`C` `ESP-IDF` `FreeRTOS` `ESP32-C3`

### [Industrial Processing System](https://github.com/marijelaveljkovic/IndustrialProcessingSystem)
Multithreaded job processing service with a thread-safe priority queue, retry logic, event-based logging and periodic reports. Covered by 43 unit tests running in a GitHub Actions CI pipeline.
`C#` `.NET 8` `xUnit` `GitHub Actions`

### [Hydraulic Drive Control](https://github.com/marijelaveljkovic/hydraulic-drive-control-labview)
Real-time control of a three-cylinder hydraulic system on NI CompactRIO: state machine control logic with edge detection, controlled shutdown and emergency stop, plus a SCADA interface over network shared variables. Team project.
`LabVIEW` `LabVIEW Real-Time` `CompactRIO`

### [Online News Popularity Prediction](https://github.com/marijelaveljkovic/online-news-popularity-prediction)
Regression on ~39,000 news articles comparing linear models, Random Forest and XGBoost, with feature engineering, hyperparameter tuning and an analysis of model limitations.
`Python` `scikit-learn` `XGBoost` `pandas`
